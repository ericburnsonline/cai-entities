# Insurance Types

## Source

The initial insurance-type list was based on information from State Farm:

https://www.statefarm.com/simple-insights/residence/what-are-all-the-different-types-of-insurance

## Dataset Notes

Synonyms were added manually to improve recognition of common alternative terms.

The dataset is intended as a reusable starting point for Conversational AI applications involving insurance products and may be expanded as additional terminology and use cases are identified.
