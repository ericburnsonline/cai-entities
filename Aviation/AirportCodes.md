# Airport Codes

## Source

The initial airport-code dataset was based on information from:

http://www.airportcodes.org/

## Dataset Notes

The current dataset contains more than 3,500 airport-code entries.

Further cleanup may include:

- Checking for duplicate entries
- Normalizing location and city naming
- Sorting entries consistently
- Expanding coverage with additional airport codes

The dataset is intended as a reusable reference for Conversational AI applications involving travel, booking, transportation, or location recognition.
